개인정보처리방침

AI 일본 여행 회화 퀴즈 웹앱 수업 가이드 · 적용일: 2026년 10월 25일

이 웹페이지는 일회성 교육·체험 수업을 지원하기 위해 제작한 정적 웹앱입니다. 웹앱 자체의 개인정보 처리 여부와 외부 서비스 이용 시 발생할 수 있는 정보 처리를 다음과 같이 안내합니다.

1. 웹앱 자체의 개인정보 수집·저장 여부

  • 회원가입·로그인 기능이 없으며 학생의 이름, 학번, 연락처 등 개인정보를 직접 입력받거나 수집하지 않습니다.
  • 학습 기록, 평가 결과, 주제·테마 선택 또는 체크리스트 상태를 웹앱 운영자의 서버나 데이터베이스에 저장하지 않습니다.
  • 웹앱 자체에서 쿠키, localStorage, sessionStorage를 이용해 사용자 정보를 저장하지 않습니다. 화면의 일시적인 선택 상태는 새로고침 시 초기화됩니다.
  • 웹앱 자체는 생성형 AI API에 연결하지 않으며, 복사한 프롬프트를 AI 서비스에 자동으로 전송하지 않습니다.

2. 호스팅 및 외부 리소스 이용

이 페이지는 GitHub Pages로 게시되며 화면 표시를 위해 GitHub Pages, Tailwind CSS CDN, Google Fonts 등의 외부 서비스를 이용합니다. 페이지 접속 및 리소스 다운로드 과정에서 IP 주소, 브라우저·기기 정보, 접속 시각 등의 기술적 정보가 각 서비스 제공자에게 전달되거나 해당 제공자의 정책에 따라 처리될 수 있습니다. 이는 이 웹앱 자체의 학생 정보 수집·저장 기능과는 구분됩니다.

관련 정책은 GitHub 개인정보 처리 안내 및 Google 개인정보처리방침 등 각 제공자의 공식 문서를 참고해 주시기 바랍니다.

3. 외부 생성형 AI 서비스 이용

수업 중 학생이 이 페이지에서 프롬프트를 복사한 후 Gemini Canvas 등 외부 AI 서비스에 직접 입력하는 경우, 해당 입력 내용과 계정 정보의 처리는 그 외부 서비스의 약관과 개인정보처리방침을 따릅니다. 이 웹앱이 해당 내용을 자동 수집하거나 전송하는 것은 아닙니다.

외부 AI 서비스에 개인정보나 민감한 학교·학생 정보를 입력하지 않도록 주의해 주시기 바랍니다.

4. 보유·파기 및 문의

이 웹앱 자체는 학생 개인정보를 별도로 저장하지 않으므로 웹앱 운영자에게 보관되는 학습자 개인정보의 보유·파기 절차는 없습니다. 외부 서비스에서 처리되는 기술적 정보와 AI 입력 내용의 보유·삭제는 각 서비스 정책을 따릅니다.
